# 初始服务资产清单

| 服务 | 当前结论 | 依据 |
|---|---|---|
| HomeNAS API | 本地开发中 | 项目自身健康端点 |
| Seafile CE | 未确认 | 目标 NAS 需审计部署方式和健康地址 |
| Mihomo | 未确认 | 只读探测二进制和固定 Controller 配置；不读取 Secret |
| Tailscale | 未确认 | 只读探测二进制和状态接口 |
| Docker | 未确认 | 目标 NAS 需检查 Docker 是否安装 |
| 现有反向代理 | 未确认 | 不扫描、不修改监听配置 |

端口开放不能单独证明服务身份；第一版只保留固定白名单服务条目。
